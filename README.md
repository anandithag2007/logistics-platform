# Logistics Platform

A full-stack logistics management application built using:

- React
- Node.js
- Express.js
- MySQL
- JWT Authentication

## Features

- User Registration
- User Login
- Secure JWT Authentication
- Create Shipments
- View Shipments
- Update Shipment Status
- Delete Shipments
- Dashboard Statistics
- Responsive Design

## Tech Stack

Frontend:
- React
- Axios
- React Router

Backend:
- Node.js
- Express.js

Database:
- MySQL

Authentication:
- JWT
